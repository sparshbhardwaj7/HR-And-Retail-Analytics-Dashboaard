# 📊 Power BI Analytics Dashboards — Employee Insights & Retail Sales

A collection of interactive Power BI dashboards demonstrating end-to-end business intelligence workflows — from data modeling and SQL-based extraction to DAX-driven KPI calculation and executive-level visualization design.

---

## 📖 Overview

This repository contains two dashboard projects developed as part of a hands-on Data Science and Analytics summer training program at **BVCOE, New Delhi**. Both dashboards focus on transforming raw datasets into clear, actionable, decision-ready insights using Power BI and SQL.

---

## 📁 Dashboards

### 1. Employee Analysis Dashboard
An HR analytics dashboard providing visibility into workforce composition, performance evaluation trends, career-stage distribution, and department-wise training ROI — enabling data-driven talent management decisions.

**Highlights:**
- Department-wise employee distribution
- Performance score comparison (current vs. last quarter)
- Workforce career-stage segmentation
- Department-wise training ROI and session tracking

---

### 2. Trendkart Sales Dashboard
A multi-page executive sales dashboard delivering a 360° view of retail performance across sales trends, regional and category-wise revenue, payment method distribution, customer segmentation, and returns analysis.

**Highlights:**
- Monthly sales trend analysis with YoY comparison
- Region and state-level performance mapping
- Category-wise and payment-method-wise sales breakdown
- Customer segmentation (VIP tiering) and top-customer analysis
- Returns and return-rate tracking by category and state

---

## ⚙️ Key Features
- Fully interactive filters, slicers, and drill-through navigation
- Custom DAX measures for dynamic KPI calculation
- Relational data modeling across multiple tables
- Clean, executive-ready UI/UX design across all pages

---

## 🛠️ Tech Stack
`Power BI` · `DAX` · `SQL` · `Data Modeling` · `Data Visualization`

---

## 🚀 How to View

1. Clone or download this repository
2. Open the `.pbix` files using [Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/downloads) (free)
3. Interact with the filters, slicers, and navigation buttons to explore the dashboards

> Power BI Desktop is required to open and interact with `.pbix` files, as GitHub cannot render them natively.
